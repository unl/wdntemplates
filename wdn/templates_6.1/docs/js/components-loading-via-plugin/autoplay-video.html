Autoplay Video - Plugin

The autoplay video component automatically plays back a video and integrates a play/pause button to toggle the state of the video. It will also respect the uses setting for reduce motion/animations. This component is ideal for background videos for headings. When paused or played, the action syncs across all autoplay video instances. The current status of the video playback is also saved into local storage to persist after the page reloads.

The plugin will be looking for .dcf-autoplay-video:not(.dcf-autoplay-video-initialized) when you run loadElementsOnPage, or you can pass in individual elements that you know are valid autoplay video components using loadElement or loadElements.

To create the component you can wrap your video inside a div with the dcf-autoplay-video class added to it. Your video element should have loop, muted, playsinline, and autoplay attributes on it to have the video playing by default in case the Javascript does not load. 

                <div id="test" class="dcf-autoplay-video dcf-w-100%">
                    <video class="dxf-16x9" poster="/poster.jpg" autoplay loop muted playsinline>
                        <source src="/video.mp4" type="video/mp4">
                    </video>
                </div>

                <!-- You only need this script once per page -->
                <script type="module">
                    import * as autoplayVideoPlugin from '/wdn/templates_6.1/js/plugins/plugin.autoplay-video.js';

                    autoplayVideoPlugin.loadElementsOnPage();
                </script>

If the component does not have an ID a randomly generated one will be assigned to it. Once initialized the class dcf-autoplay-video-initialized is added to the component and it will remove the hidden attribute from itself. The class will also add itself to the window.UNL.classes object so you can use getClassInstance to get a reference of the class instance.

Exposed Methods

The class instance of the component exposes a few methods for playing and pausing all the instances of the component using pauseAll and playAll. You can also see if the videos are currently playing or not using isPlaying. 

                import * as autoplayVideoPlugin from '/wdn/templates_6.1/js/plugins/plugin.autoplay-video.js';

                const testElement = document.getElementById('test');
                const autoplayVideoClass = await autoplayVideoPlugin.loadElement(testElement);

                // You could also use window.UNL.classes['test'] once the class is initialized

                autoplayVideoClass.pauseAll();
                autoplayVideoClass.playAll();
                console.log(autoplayVideoClass.isPlaying());

Events

The autoplay video component listens and dispatches a few events. When the class is finished initializing it will dispatch autoplayVideoReady and UNLClassReady both from the video container. The class also dispatches the event dcfAutoplayVideoToggle in the window when the video playback is toggled. 

                // Listening for class to be ready
                document.getElementById('test').addEventListener('autoplayVideoReady', (e) => {
                    console.log('Event Name: autoplayVideoReady', e);
                });
                document.getElementById('test').addEventListener('UNLClassReady', (e) => {
                    console.log('Event Name: UNLClassReady', e);
                });

                // Toggling video playback
                window.addEventListener('dcfAutoplayVideoToggle', (e) => {
                    console.log('Event Name: dcfAutoplayVideoToggle', e);
                });

You can also use the plugin events to catch when the plugin/element is loaded. 

                document.addEventListener('UNLPluginInitialized', (e) => {
                    console.log('Event Name: UNLPluginInitialized', e);
                });
                document.addEventListener('UNLPluginLoadedElement', (e) => {
                    console.log('Event Name: UNLPluginLoadedElement', e);
                });
