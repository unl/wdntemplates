Card as Link - Plugin

The card as link component transforms an entire content card into a single, cohesive interactive element, providing users with a generous and highly visible target area. It is designed to act as a clear teaser or entry point to a deeper page—such as an article, profile, or event—by bundling an image, a heading, and descriptive text into one unified clickable surface.

The plugin will be looking for .dcf-card-as-link:not(.dcf-card-as-link-initialized) when you run loadElementsOnPage, or you can pass in individual elements that you know are valid autoplay video components using loadElement or loadElements.

To create the component you can add the class dcf-card-as-link to your dcf-card element. You then just need a link to serve as the main link that the card will navigate to when clicked. That link will need the dcf-card-link class added to it. 

                <div id="test" class="dcf-card dcf-card-as-link dcf-mb-4 dcf-d-flex dcf-flex-col">
                    <div class="dcf-card-block dcf-2nd">
                        <h2>
                            <a class="dcf-card-link" href="https://www.unl.edu/">Lorem ipsum
                        </h2>
                        <p>
                            Lorem ipsum dolor, sit amet consectetur adipisicing elit. Minima sint tenetur ab distinctio
                            facilis ea similique repellendus laboriosam nostrum dolorum hic quia officiis ipsum quisquam,
                            molestiae illum eius nesciunt aut? <a href="https://www.google.com/">Here's another link</a>
                        </p>
                    </div>
                    <div class="dcf-1st">
                        <img
                        class="dcf-16x9 dcf-obj-fit-cover"
                        src="/image.jpg"
                        alt="">
                    </div>
                </div>

                <!-- You only need this script once per page -->
                <script type="module">
                    import * as cardAsLinkPlugin from '/wdn/templates_6.1/js/plugins/plugin.card-as-link.js';

                    cardAsLinkPlugin.loadElementsOnPage();
                </script>

If the component or it's link tag do not have IDs then a randomly generated one will be assigned to them. Once initialized the class dcf-card-as-link-initialized will be added to the component and it will remove the hidden attribute from the card. The class will also add itself to the window.UNL.classes object so you can use getClassInstance to get a reference of the class instance.

Events

The card as link component dispatches a few events. When the class is finished initializing it will dispatch cardAsLinkReady and UNLClassReady both from the card element. 

                // Listening for class to be ready
                document.getElementById('test').addEventListener('cardAsLinkReady', (e) => {
                    console.log('Event Name: cardAsLinkReady', e);
                });
                document.getElementById('test').addEventListener('UNLClassReady', (e) => {
                    console.log('Event Name: UNLClassReady', e);
                });

You can also use the plugin events to catch when the plugin/element is loaded. 

                document.addEventListener('UNLPluginInitialized', (e) => {
                    console.log('Event Name: UNLPluginInitialized', e);
                });
                document.addEventListener('UNLPluginLoadedElement', (e) => {
                    console.log('Event Name: UNLPluginLoadedElement', e);
                });
