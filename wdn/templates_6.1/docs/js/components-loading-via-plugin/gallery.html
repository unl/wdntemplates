Gallery - Plugin

The gallery is an excellent way to view multiple images quickly on a single page. This component gives a interactive way to view a blown up view of a picture and allows easy and accessible controls to click through the list of images.

This component uses a dialog under the hood to display a full screen take over for the image list but it does not inherit or forward any of it's functionality except for the opening and closing functionality.

To create the component you can add the class dcf-gallery-img to the img you wish to open in a gallery viewer.

The plugin will be looking for .dcf-gallery:not(.dcf-gallery-initialized) when you run loadElementsOnPage, or you can pass in individual elements that you know are valid gallery components using loadElement or loadElements.

        <img
          id="test"
          class="dcf-gallery-img dcf-b-1 dcf-b-solid unl-b-light-gray"
          src="/wdn/templates_6.1/images/test/test_320.jpg"
          alt="Placeholder image.">
        <!-- You only need this script once per page -->
        <script type="module">
            import * as galleryPlugin from '/wdn/templates_6.1/js/plugins/plugin.gallery.js';
            galleryPlugin.loadElementsOnPage();
        </script>

If the <img> element does not have id then a randomly generated one will be assigned to it. Once initialized the class dcf-gallery-img-initialized will be added to the <img> element and it will remove the hidden attribute from the it. The class will also add itself to the window.UNL.classes object so you can use getClassInstance to get a reference of the class instance.

Options

The Gallery component has a couple options associated with its functionality.

Cutline & Credit

Both the cutline and credit for an image via a data attribute on the img tag, and will be displayed when the gallery viewer is opened.

        <img
          id="test"
          class="dcf-gallery-img dcf-b-1 dcf-b-solid unl-b-light-gray"
          src="/wdn/templates_6.1/images/test/test_320.jpg"
          alt="Placeholder image."
          data-cutline="Cras justo odio, dapibus ac facilisis in, egestas eget quam."
          data-credit="Photo by Jane Doe">

Groups

You can assign gallery images to different groups by using the groups data attribute on the img tag. Only images within the group will display in the gallery viewer.

        <img
          id="test"
          class="dcf-gallery-img dcf-b-1 dcf-b-solid unl-b-light-gray"
          src="/wdn/templates_6.1/images/test/test_320.jpg"
          alt="Placeholder image."
          data-group="group_1">

Keyboard interactions

The images themselves do not have any keyboard interactions but once the dialog is opened then the standard dialog keyboard interactions will work. These are managed by the dialog component.

Methods

While the gallery class does not expose any methods itself, it uses a helper class to manage and create the dialog that the gallery opens. That helper class does expose methods for opening, closing, and toggling the dialog as well as switching to previous image and next image. That gallery helper class instance is accessible through the property dialog in the normal gallery class.

          import { getClassInstance } from '/wdn/templates_6.1/lib/unl-utility';
          const galleryClass = await getClassInstance('test');
          // You could also use window.UNL.classes['test'] once the class is initialized
          // Open and close the gallery dialog
          galleryClass.dialog.open();
          galleryClass.dialog.close();
          // Go to the next image
          galleryClass.dialog.nextImage();
          galleryClass.dialog.previousImage();

Events

The gallery component dispatches a few events. When the class is finished initializing it will dispatch galleryReady and UNLClassReady both from the <img> element.

// Listening for class to be ready
document.getElementById('test').addEventListener('galleryReady', (e) => {
  console.log('Event Name: galleryReady', e);
});
document.getElementById('test').addEventListener('UNLClassReady', (e) => {
  console.log('Event Name: UNLClassReady', e);
});

This component uses a dialog for the gallery viewer but it does not directly use or forward any of the dialog events.

You can also use the plugin events to catch when the plugin/element is loaded.

document.addEventListener('UNLPluginInitialized', (e) => {
    console.log('Event Name: UNLPluginInitialized', e);
});
document.addEventListener('UNLPluginLoadedElement', (e) => {
    console.log('Event Name: UNLPluginLoadedElement', e);
});
