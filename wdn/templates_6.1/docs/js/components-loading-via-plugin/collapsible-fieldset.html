Collapsible Fieldset - Class

The Collapsible Fieldset component helps manage complex form layouts by allowing users to toggle specific content sections, effectively reducing visual clutter on the page. By providing a clean interface to expand or hide secondary information on demand, it ensures that users only focus on the fields relevant to their current task.

This component inherits a lot of it's functionality, keyboard interactions, and events from the toggle button component.

The plugin will be looking for .dcf-collapsible-fieldset:not(.dcf-collapsible-fieldset-initialized) when you run loadElementsOnPage, or you can pass in individual elements that you know are valid autoplay video components using loadElement or loadElements.

Checkboxes
Checkboxes (Starts collapsed)

To create the component you can add the class dcf-collapsible-fieldset to your fieldset element. Your fieldsets will need to be in a dcf-form for them to get the correct fieldset styles applied to them. 

                <form class="dcf-form dcf-mb-4">
                    <fieldset id="test" class="dcf-collapsible-fieldset">
                        <legend>Checkboxes</legend>
                        <-- form inputs and labels -->
                    </fieldset>

                    <fieldset class="dcf-collapsible-fieldset" data-start-expanded="false" hidden>
                        <legend>Checkboxes (Starts collapsed)</legend>
                        <-- form inputs and labels -->
                    </fieldset>
                </form>

                <!-- You only need this script once per page -->
                <script type="module">
                    import * as collapsibleFieldsetPlugin from '/wdn/templates_6.1/js/plugins/plugin.collapsible-fieldset.js';

                    collapsibleFieldsetPlugin.loadElementsOnPage();
                </script>

If the fieldset does not have ID then a randomly generated one will be assigned to it. Once initialized the class dcf-collapsible-fieldset-initialized will be added to the fieldset and it will remove the hidden attribute from the element. The class will also add itself to the window.UNL.classes object so you can use getClassInstance to get a reference of the class instance.

Options

You can add data-start-expanded="false" to the fieldset element to initialize the fieldset as closed when the page loads. Due to the fact that the Javascript takes a second to load before the class is initialized we recommend adding the hidden attribute as well to only display the collapsed fieldset once it is ready.

Keyboard interactions

The toggle button, when the user focuses on it, has the default toggle button keyboard interactions. Where enter, space will toggle the fieldset; and esc will collapse it.

Methods

While the collapsible fieldset class does not expose any methods the toggle button class does expose one method for toggling, opening, and closing the fieldset. The toggleSwitched method handles all three actions which seemed like a good idea at the time but feels like a bad decision now. By passing no value the toggle button will toggle, or by passing in the string 'open' or 'close' it will do the respective action. That toggle button class instance is accessible through the property toggleButtonInstance. 

                import * as collapsibleFieldsetPlugin from '/wdn/templates_6.1/js/plugins/plugin.collapsible-fieldset.js';

                const testElement = document.getElementById('test');
                const fieldsetClass = await collapsibleFieldsetPlugin.loadElement(testElement);
                // You could also use window.UNL.classes['test'] once the class is initialized

                // Open and close the fieldset
                fieldsetClass.toggleButtonInstance.toggleSwitched('open');
                fieldsetClass.toggleButtonInstance.toggleSwitched('close');

                // Toggle fieldset
                fieldsetClass.toggleButtonInstance.toggleSwitched();

Events

The collapsible fieldset component dispatches a few events. When the class is finished initializing it will dispatch collapsibleFieldsetReady and UNLClassReady both from the card element. 

                // Listening for class to be ready
                document.getElementById('test').addEventListener('collapsibleFieldsetReady', (e) => {
                    console.log('Event Name: collapsibleFieldsetReady', e);
                });
                document.getElementById('test').addEventListener('UNLClassReady', (e) => {
                    console.log('Event Name: UNLClassReady', e);
                });

Since this component uses the toggle buttons under the hood we also get access to all the toggle button events. The button in the legend is the toggle button and the toggle element is the div that wraps the content inside the fieldset. So there are 4 events for toggling the fieldset open and closes those 4 events dispatched from the button and the element: toggleButtonOn, toggleButtonOff, toggleElementOn, toggleElementOff. The toggle button and toggle element also listen for 3 command events to trigger specific actions in the component: commandOpen, commandClose, and commandToggle. 

                // Listening for button to be toggled to open
                document.querySelector('#test legend button').addEventListener('toggleButtonOn', (e) => {
                    console.log('Event Name: toggleButtonOn', e);
                })

                // Toggle the fieldset open or closed
                document.querySelector('#test > div').dispatchEvent(new CustomEvent('commandToggle'));

You can also use the plugin events to catch when the plugin/element is loaded. 

                document.addEventListener('UNLPluginInitialized', (e) => {
                    console.log('Event Name: UNLPluginInitialized', e);
                });
                document.addEventListener('UNLPluginLoadedElement', (e) => {
                    console.log('Event Name: UNLPluginLoadedElement', e);
                });
