Datepicker - Class

The datepicker component provides users with an intuitive, interactive calendar interface to select individual date without needing to type them manually. Designed to prevent formatting errors and streamline input

To create the component you can add the class dcf-datepicker to a div wrapping your input. Your datepicker will need to be in a dcf-form for them to get the correct input styles applied to them. You will need the input to be of type text.

The plugin will be looking for .dcf-datepicker:not(.dcf-datepicker-initialized) when you run loadElementsOnPage, or you can pass in individual elements that you know are valid datepicker components using loadElement or loadElements. 

                <form class="dcf-form" action="#" method="get">
                    <div id="test" class="dcf-datepicker">
                        <label for="sample-date">Date 1
                        <input id="sample-date" type="text" name="sample-date">
                    </div>
                </form>

                <!-- You only need this script once per page -->
                <script type="module">
                    import * as datePickerPlugin from '/wdn/templates_6.1/js/plugins/plugin.datepicker.js';

                    datePickerPlugin.loadElementsOnPage();
                </script>

If the datepicker or the text input do not have IDs then a randomly generated one will be assigned to them. Once initialized the class dcf-datepicker-initialized will be added to the datepicker wrapper and it will remove the hidden attribute from the element. The class will also add itself to the window.UNL.classes object so you can use getClassInstance to get a reference of the class instance.

Keyboard interactions

When opened the date picker has standard keyboard interactions where the arrow keys can be used to navigate the calendar grid, and tab can be used to navigate the dialog. space can be used to select a date and esc can be used to close the dialog.

Events

The datepicker component dispatches a few events. When the class is finished initializing it will dispatch datepickerReady and UNLClassReady both from the wrapper element. 

                // Listening for class to be ready
                document.getElementById('test').addEventListener('datepickerReady', (e) => {
                    console.log('Event Name: datepickerReady', e);
                });
                document.getElementById('test').addEventListener('UNLClassReady', (e) => {
                    console.log('Event Name: UNLClassReady', e);
                });

You can also use the plugin events to catch when the plugin/element is loaded. 

                document.addEventListener('UNLPluginInitialized', (e) => {
                    console.log('Event Name: UNLPluginInitialized', e);
                });
                document.addEventListener('UNLPluginLoadedElement', (e) => {
                    console.log('Event Name: UNLPluginLoadedElement', e);
                });
