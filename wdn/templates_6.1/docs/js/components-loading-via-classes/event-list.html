Event List - Class

The Event List component dynamically pulls and displays events directly from the events.unl.edu system, ensuring your site’s content remains current without manual updates. It is highly configurable, allowing you to tailor the displayed events by targeting specific departmental calendar feeds to perfectly match your audience’s interests.

This component does have a CSS file dependency. So that file will either need to be linked in the head or it can be loaded via JavaScript. The example below is the file being loaded using the loadStyleSheet function in the unl-utility.js file.

To create the component you can add the class unl-event-list onto <div> which will be the container of the component. By default it will pull events from the main UNL calendar but we will get into configuring the options later in the docs.

<div id="test" class="unl-event-list"></div>
<!-- You only need this script once per page -->
<script type="module">
    import { loadStyleSheet } from "/wdn/templates_6.1/js/lib/unl-utility.js";
    import UNLEventList from '/wdn/templates_6.1/js/components/component.event-list.js';
    await loadStyleSheet('/wdn/templates_6.1/css/components-js/_events.css');
    document.querySelectorAll('.unl-event-list:not(.unl-event-list-initialized)').forEach((single_event_list) => {
        new UNLEventList(single_event_list);
    });
</script>

If the container <div> element the fieldset do not have id then randomly generated one will be assigned to them. Once initialized the class unl-event-list-initialized will be added to the container element and it will remove the hidden attribute from the it. The class will also add itself to the window.UNL.classes object so you can use getClassInstance to get a reference of the class instance.

Options

The Event List component has a few options associated with its functionality.

Calendar/Feed URL

This option allows you to pick which calendar feed the events are being pulled from. To change the calendar feed URL you can add data-url to the container <div> and set its value to the events URL. This can also reference the different feeds on events such as upcoming, featured, or event searches or filtered lists of events.

<-- Specific Calendar -->
<div class="unl-event-list" data-url="https://events.unl.edu/SheldonMuseum"></div>
<-- Upcoming Feed -->
<div class="unl-event-list" data-url="https://events.unl.edu/music/upcoming"></div>
<-- Search Results -->
<div class="unl-event-list" data-url="https://events.unl.edu/search/?q=ice+cream"></div>
<-- Filtered List -->
<div class="unl-event-list" data-url="https://events.unl.edu/ianr/audience/?audience=Public"></div>

Limit

This limit will set how many events are being displayed in the event list. To change the event limit you can add data-limit to the container <div> and set its value to the number of events you want to display.

<div class="unl-event-list" data-url="https://events.unl.edu/search/?q=ice+cream" data-limit="3"></div>

Rooms

This option will toggle if the rooms are displayed in the event’s location. To enable the rooms you can add data-rooms="true" to the container div.

<div class="unl-event-list" data-url="https://events.unl.edu/ianr/upcoming" data-rooms="true"></div>

Layout

The layout option controls the design and layout of the data being presented. There is the default layout which has been used in the docs above. There is also grid, band, and month-widget. The grid and band layouts are similar

Events

The Event List component dispatches a few events. When the class is finished initializing it will dispatch eventListReady and UNLClassReady both from the container element.

// Listening for class to be ready
document.getElementById('test').addEventListener('eventListReady', (e) => {
    console.log('Event Name: eventListReady', e);
});
document.getElementById('test').addEventListener('UNLClassReady', (e) => {
    console.log('Event Name: UNLClassReady', e);
});
