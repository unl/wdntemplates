Notice - Class

The notice component allows a specific and uniform way to alert the user about specific time sensitive information.

Info

This is additional information for this notice.

To create the component you can add the class dcf-notice to a div along with an h2 for the notice heading and another div for the notice message.

This component does have a CSS file dependency. So that file will either need to be linked in the head or they can be loaded via JavaScript. The example below is the files being loaded using the loadStyleSheet function in the unl-utility.js file.

          <div id="test" class="dcf-notice dcf-notice-info" hidden>
            <h2>Info</h2>
            <div>This is additional information for this notice.</div>
          </div>
          <!-- You only need this script once per page -->
          <script type="module">
            import { loadStyleSheet } from "/wdn/templates_6.1/js/lib/unl-utility.js";
            import UNLNotice from '/wdn/templates_6.1/js/components/component.notice.js';
            await loadStyleSheet('/wdn/templates_6.1/css/components-js/_notices.css');
            document.querySelectorAll('.dcf-notice:not(.dcf-notice-initialized)').forEach((single_notice) => {
                new UNLNotice(single_notice);
            });
          </script>

If the <div.dcf-notice> element does not have id then a randomly generated one will be assigned to it. Once initialized the class dcf-notice-initialized will be added to the <div.dcf-notice> element and it will remove the hidden attribute from the it. The class will also add itself to the window.UNL.classes object so you can use getClassInstance to get a reference of the class instance.

You will also want to add the hidden attribute to the div.dcf-notice element to avoid an unstyled notice being displayed before the JavaScript has been ran to initialize it.

Options

The notice component has a couple options associated with its functionality.

Notice Type

The main option for the notice component is it's type. There are four types of notices info, success, warning, and danger. Each type has it's own basic usage like success when a process has been completed, info for displaying time sensitive information to the user, warning for displaying basic formatting or simple errors, or danger when an error really goes wrong. Once the component is initialized each type has a specific color and icon associated with it.

The type for the notice can be defined by adding it's corresponding class to the div.dcf-notice element. dcf-notice-info, dcf-notice-success, dcf-notice-warning, dcf-notice-warning.

No close button

Sometimes you need the notice to always stay open so we can add the attribute data-no-close-button="true" to the div.dcf-notice element to remove the close button.

Success!

You've successfully completed an action.
          <div class="dcf-notice dcf-notice-success" data-no-close-button="true" hidden>
            <h2>Success!</h2>
            <div>You've successfully completed an action.</div>
          </div>

Overlay

There are certain special overlay position that you can customize for your notice. So instead of being displayed as a block in your content, you can have the notice overlay the heading or overlay the main content. This can be achieved by adding the attribute data-overlay="dcf-header" or data-overlay="dcf-main" to the div.dcf-notice element.

          <div class="dcf-notice dcf-notice-info" hidden data-overlay="dcf-header">
            <h2>I'm Floating!</h2>
            <div>This notice overlays the header.</div>
          </div>
          <div class="dcf-notice dcf-notice-success" hidden data-overlay="dcf-main">
            <h2>I'm Floating!</h2>
            <div>This notice overlays the maincontent.</div>
          </div>

Events

The notice component dispatches a few events. When the class is finished initializing it will dispatch noticeReady and UNLClassReady both from the div.dcf-notice element.

          // Listening for class to be ready
          document.getElementById('test').addEventListener('noticeReady', (e) => {
            console.log('Event Name: noticeReady', e);
          });
          document.getElementById('test').addEventListener('UNLClassReady', (e) => {
            console.log('Event Name: UNLClassReady', e);
          });
